# Contributing

Corrections and suggestions are welcome, especially from people who work with the CESM2 Large Ensemble or teach machine learning
in the geosciences.

- **Found an error?** Open an issue with the page or notebook cell, what it says, and what it should say, with a source if you
  have one.
- **Want to add a case or an exercise?** Open an issue first describing the objective it serves, so it fits the course's five.
- **Pull requests:** keep notebooks committed with outputs cleared, and credit any image you add with its source and licence.

By contributing you agree that your contribution is licensed under this repository's terms (CC BY 4.0 for content, Apache-2.0
for code).
